Best-Rated Books, By Genre and By Decade

Emily Schallenberg · Financial Data Analytics · Data Website Project

This report looks at 45,203 books from Goodreads' "Best Books Ever" list — each one tagged with one or more of 25 major genres and a publication year spanning 1873 to 2021 — to ask which genres actually earn the highest reader ratings, whether that answer has changed over time, and what else (format, length, popularity) moves the needle on a book's rating.

How the numbers are computed
"Average rating" is the mean of each book's own Goodreads average rating (not a rating recomputed from individual reviews, which aren't in this dataset). "Median rating" is the middle value of that same list. "Total ratings" sums each book's numRatings field. A genre's or decade's "share of books" is its count of books divided by the total book count in the same comparison group. All of these are computed client-side, live, from assets/data/books.json — the same file and the same functions (js/agg.js) power both this report and the dashboard, so the two pages always agree.
